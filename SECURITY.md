# Security

These development plugins run as your user inside the long-lived Omarchy shell. Review code before enabling it; automated tests are not a security audit.

Please do not publish private window titles, clipboard contents, application libraries, tokens, desktop captures or broad process/configuration logs.

Use this repository's **Security → Report a vulnerability** option when available. If private reporting is unavailable, open an issue asking for a private contact without disclosing the vulnerability. Never include credentials or private data in a public issue.
