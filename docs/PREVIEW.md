# Preview provenance

The root preview is a **real native Qt/Quickshell card capture** from an isolated headless compositor, with an on-image **Native UI · illustrative catalogue** caption and an in-panel disclosure that actions were not exercised. It is not a real desktop/app/game screenshot, installed library, measurement or action confirmation.

Original geometric artwork, colour studies and fictional monograms are GPL-3.0-only. Their preferred SVG sources, when used, are included under `preview-source/`; native UI source is the matching versioned runtime. The glyph preview uses the bundled symbol catalogue rendered with an existing installed font. Existing catalogue/font/component rights remain separate; no font binaries are bundled or relicensed. No copyrighted game art, third-party wallpaper, private desktop data, or Mosaic code/assets are copied.

The illustrative fixture changed only catalogues in the private capture harness. All shipped action, validation, cancellation and recovery code is the actual plugin source; the preview does not substitute for its tests. Private benchmark logs and reproduction records are intentionally not distributed. The image is metadata-stripped; the current runtime remains independent of these documentation-only assets.
